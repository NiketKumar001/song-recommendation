# 🎵 Song Recommendation System

A content-based song recommender built with Python and Streamlit. Pick a song from the dropdown and get 5 similar tracks, each with album art and a short audio preview.

> 🔗 **Live demo:** _add your Streamlit Cloud link here_

---

## ✨ Features

- 🎯 **Content-based recommendations** using Spotify audio features (danceability, energy, loudness, acousticness, etc.)
- 🧹 **Duplicate-aware results**: regex-based name cleaning removes alternate versions of the same song (e.g. `Song (From "Movie")` vs `Song - Lofi Flip`) so recommendations stay diverse
- 🖼️ **Album art + audio preview** fetched live from the iTunes Search API (no API key needed)
- ⚡ **Fast reruns** with `@st.cache_data`, so a song is only looked up once
- 🎨 Clean Streamlit UI with a searchable dropdown

---

## 🧠 How it works

1. **Data:** Spotify tracks dataset (Hindi songs, ~1000 rows, 963 after removing duplicates).
2. **Features used:** `popularity`, `danceability`, `energy`, `loudness`, `acousticness`, `instrumentalness`, `liveness`, `valence`.
3. **Scaling:** features are standardised with `StandardScaler` so that columns like `loudness` (negative dB values) and `popularity` (0-100) contribute fairly.
4. **Similarity:** `cosine_similarity` on the scaled feature matrix gives a 963 x 963 similarity matrix.
5. **Recommendation:** for the chosen song, scores are sorted in descending order. The song itself and alternate versions of it are skipped using a cleaned-name check, and the top 5 are returned.
6. **Extras:** for each recommendation, the iTunes Search API returns album artwork and a 30 sec preview (the app plays the first 20 sec).

## 🚀 Run locally

```bash
# 1. Clone the repo
git clone https://github.com/<your-username>/<your-repo>.git
cd <your-repo>

# 2. (Optional) create a virtual environment
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # macOS / Linux

# 3. Install dependencies
pip install -r requirements.txt

# 4. Start the app
streamlit run app.py
```

The app opens at `http://localhost:8501`.

> 💡 `songs.pkl` and `similarity.pkl` are generated by `main.ipynb`. They are already included in the repo, so you only need to re-run the notebook if you change the dataset or features.

## ⚠️ Limitations

- Recommendations are based only on audio features, not on lyrics, language, or listening history.
- The iTunes search is text-based, so a rare song may occasionally match the wrong track or return no preview. In that case the app simply shows the name and artist.
- The dataset is small (~1000 songs), so results are limited to what it contains.
